# Texas classroom crosswalks

Create a teacher-facing companion to the source. Make it possible to teach one activity tomorrow and recognize the learning in a student's work. Default to an actual horizontal infographic for this series. Honor requests for a text table, draft copy, handout, or another format.

## Build the crosswalk

1. Read the supplied article or resource. Capture the exact title, author/publisher, intended grades, named activities, materials, and canonical resource URL. Prefer the user's current URL over a retired mirror. Preserve tool capitalization and framework terminology. Ignore navigation, ads, unrelated promotions, duplicate bylines, and tracking parameters. If details are missing, use the material available and avoid unsupported features, counts, URLs, and standards codes.
2. Identify the thinking each activity elicits. Find a decision, misconception, or explanation the teacher could actually hear or see. Distinguish a feature supplied by the author from an instructional adaptation you propose. Use language like “Ask students to…” for an adaptation. If the headline promises seven routines, represent all seven, combining related routines when useful, or explicitly title the image as a selection.
3. Draft a three-column table: **Program connection | Classroom example | What to document**. Adapt the middle heading to the article, e.g., “Bellringer prompt.” Use the five familiar rows below when each can be supported. If the source only fits some rows, omit weak matches or describe a clearly feasible adaptation. For a non-instructional source with no plausible classroom use, explain the mismatch. Keep finance, purchasing, and eligibility language out of an instructional crosswalk.
4. Write the middle cell as an action a teacher can assign. Name the material, ask for a decision or explanation, and keep the grade and subject credible. Write the last cell as a specific artifact or observation plus what to look for in it. A completed page, screenshot, or attendance count alone says little. Prefer “Save the prediction and revised graph. Mark where the student explains the unchanged intercept.” Avoid real student identifiers.
5. Apply the three optional tests in [Framework decisions](references/framework-decisions.md). Treat them independently. Zero additions is a complete result. Include a short callout for one task or a compact companion note if context or citations would crowd the image. Keep the classroom example and documentation prominent.
6. Render and inspect the actual result using the visual specification below. Deliver the requested artifact with a short caption and a working resource link when available.

## Choose the core rows

| Program connection | Instructional fit | Example of evidence |
|---|---|---|
| Title I-A | Address a specific academic need such as connecting text evidence to a claim. If schoolwide or targeted assistance is discussed, distinguish the campus plan from service to identified students. | Keep first and revised claims; mark the detail that strengthens the second. |
| Title III-A | Identify a language function for emergent bilingual students, such as comparing, sequencing, or explaining cause. Design an opportunity to use English with relevant supports. A translated interface alone supplies no language-learning task. | Capture a student's clarifying question and the revised direction that resolved the ambiguity. |
| Title IV-A | Name the well-rounded academic, arts, STEM, or purposeful technology experience. Make the subject-specific decision explicit. | Keep the route before and after debugging and the student's reason for revising a command. |
| IDEA Part B | Connect the task to an individual student's documented need or IEP support. Keep the target accessible and the thinking intact. Phrase the example conditionally. | Note the support used and the reasoning the student communicated in the agreed response mode. |
| Texas IMTA | Connect an identifiable instructional material to a specific TEKS-based learning goal. Use it as a materials connection. Verify any grade-specific TEKS citation against the current official standard. | Name the material and skill; keep a sample showing how the student applied it. |

## Design and proof the image

Use a 16:9 landscape canvas, white background, deep navy heading, pale blue column headers, silver dividers, and high contrast. Allow roughly one fifth of the width for program labels and the rest for the activity and documentation. Use a small Texas silhouette and a relevant illustration per row when they aid scanning. Keep people fully clothed and classroom-appropriate. Use clear sans-serif type and sentence case. Shorten copy before shrinking text.

Use a resource-specific title, a one-line subtitle, and a footer credit that matches the supplied source. Reuse the author’s credited name only when supported. Put long URLs and research citations in the accompanying caption. For image generation, provide final verbatim copy, row boundaries, and illustration notes separately. Use programmatic typesetting or plotting for exact scientific or mathematical diagrams; a decorative illustration should never make a competing factual claim.

Check the rendered image at normal reading size against the copy, row by row. Verify spelling, symbols, grade ranges, counts, program labels, source attribution, URL, accessibility of contrast, and correspondence between visuals and text. Fix errors before delivery. Supply concise alt text or a text equivalent when the user asks for an accessible publication or when important information is available only in the image.

## Example row

| Program connection | Classroom challenge | What to document |
|---|---|---|
| Title III-A | Hide a cup tower behind a screen. Have the builder ask one question in English before placing the next cup. | Record the question and revised direction. Underline the words that clarified which cup went where. |

For this row alone, leave optional labels off. A record of a useful exchange serves the instructional purpose.
