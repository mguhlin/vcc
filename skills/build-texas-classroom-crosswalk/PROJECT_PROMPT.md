# Build a Texas classroom crosswalk planner

Read and apply `SKILL.md`, `references/framework-decisions.md`, and VCC’s Web Design, Education Privacy, and SecureVCC instructions. Build a teacher-facing planner that turns a Texas K–12 educator resource into a classroom crosswalk.

Let a teacher enter the resource title, author, link, grade range, and activities. Provide editable rows for program connection, classroom example, and what to document. Each row should pair an assignable action with a specific artifact or observation and the learning to look for. Allow teachers to remove rows without a supported connection and distinguish activities from proposed adaptations.

Provide a landscape print layout and an accessible text table with matching content. Include optional notes for TIA, Webb’s DOK, and ESSA evidence tiers. Apply each framework independently and keep any supporting sources alongside the relevant claim.

Use synthetic examples, keep drafts in browser memory, and make the planner usable with keyboard and touch. Use no accounts, external AI calls, or identifiable student information. Verify the edit, text-table, and print workflows with a sample resource.
