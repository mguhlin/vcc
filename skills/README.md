# Reusable skills for vibe-coded projects

Open the [VCC skill browser](https://mguhlin.github.io/vcc/guides/skills.html) for 27 workflows, project prompts, and concept images.

Each skill folder contains `SKILL.md` and a matching `PROJECT_PROMPT.md`. Read the skill, adapt the prompt to your audience, and explicitly ask your assistant to apply it. Download VCC's `WEB_DESIGN.md`, `EDU_COMPLIANCE.md`, and `securevcc.md` from the [core guides](https://mguhlin.github.io/vcc/#core-guides) before using the project prompt. These prompts describe possible applications; this collection does not include completed apps.

[Audiobook Maker](audiobook-maker/SKILL.md) adapts Lance Eaton's [Book to Audio Edition](https://github.com/leaton79/book-to-audiobook), introduced in [AI Audiobooks: An Update](https://aiedusimplified.substack.com/p/ai-audiobooks-an-update). Its MIT notice is preserved. The [complete folder ZIP](../downloads/audiobook-maker.zip) includes the VCC project prompt and [free local audio path](audiobook-maker/references/free-local-audio.md), which follow VCC's CC BY 4.0 terms. It prepares listening text first; audio generation is optional. The [PageSpindle companion app](https://mguhlin.github.io/pagespindle/) integrates local narration, skips Markdown formatting in speech without an AI pass, and retains original formatting in source/project backups. The included reference also covers separately installed engines.

The collection ZIP preserves the `vcc/skills/` folder structure. Concept images are in `vcc/assets/skills/`. Use a text editor to read and copy files without the website. Automatic skill discovery and installation differ by assistant; saving a file alone does not guarantee activation.

The seven supplied skills, project prompts, and original concept sketches are by Miguel Guhlin, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attribute Miguel Guhlin and link to [VCC](https://mguhlin.github.io/vcc/) when sharing adaptations. Compare Options and Source Integrity retain [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/). SIFT credits Mike Caulfield's framework. See [SOURCES.md](SOURCES.md) for provenance and adaptation details.

The 14 creator adaptations include original hero artwork generated with OpenAI image generation; prompts are in `assets/skills/heroes/PROMPTS.json` in the complete bundle. ClearCopy adapts MIT-licensed material and retains its notice; the other new educational skill adaptations and project prompts follow VCC’s CC BY 4.0 terms. Consult each source notice before reuse.


Go App Builder adds application-development guidance to the collection. Its [complete folder ZIP](../downloads/go-app-builder.zip) includes platform references and a project prompt; a chatbot can read the Markdown directly, and a coding agent can use the folder through its supported skill mechanism. The references are original guidance based on linked upstream documentation, not bundled frameworks, installers, or compiled applications.

## WebDecks

[WebDecks](https://mguhlin.github.io/vcc/guides/skills.html#webdecks) adds Miguel Guhlin’s MIT-licensed Web Deck v5 presentation system. The [complete skill ZIP](https://mguhlin.github.io/vcc/downloads/webdecks.zip) includes the skill, project prompt, specification, standalone chatbot edition, framework CSS/JavaScript, starter markup, and license. The starter is downloaded as `.html.txt`; rename it to `.html` in your project. These files also travel in both skill collections and the complete VCC download. Maintain framework behavior in [mguhlin/webdecks](https://github.com/mguhlin/webdecks), then refresh these distribution snapshots.
