# Resource library

Search the guides and reusable templates by topic. Open an educator-friendly explanation or download its Markdown file for your project.

The three core instruction files cover web design, security, and education privacy. The planning and launch templates help you define the project, keep your coding assistant focused, and record the evidence before sharing.

The [reusable skills collection](skills.html) adds nine workflows with copyable instructions, project prompts, and concept sketches.

Use [Vibe-Code Rescue](rescue.html) when an existing project keeps breaking. Its setup, diagnostics, and focused repair workflow complements the security guide.
